# PrivateLedger AI

**Privacy‑First Offline Invoice & Receipt Organizer**

## Overview
PrivateLedger AI is a Streamlit‑based desktop application that lets freelancers organize receipts and invoices **offline**. It uses:
- **Tesseract OCR** (`pytesseract`) for text extraction from images.
- **PyMuPDF** to render PDF pages as images.
- A **local vision‑language model** served by **Ollama** (any compatible model, e.g., `llava` or `phi-3-vision`).
- **Pandas** for data handling and CSV/Excel export.
- **SQLite** (optional) to store extracted records.

All processing happens locally – no document data is ever sent to the cloud.

## Features
- Drag‑and‑drop upload of images/PDFs (batch support).
- Automatic OCR + local‑AI extraction of key fields (vendor, date, amounts, etc.).
- Review & edit extracted data in an editable table.
- Rename & organize files into `organized_documents/YYYY/MM/` folders.
- Export verified records to CSV or XLSX.
- Demo mode with synthetic invoices (no personal data needed).
- Privacy indicator showing if the Ollama model is available.

## Quick Start (macOS / Linux)
```bash
# 1️⃣ Clone the repo (or copy the folder you just created)
git clone <repo‑url> privateledger-ai  # or just navigate to the folder
cd privateledger-ai

# 2️⃣ Install system dependencies
# - Tesseract OCR
brew install tesseract   # macOS (use apt on Linux: sudo apt-get install tesseract-ocr)
# - Ollama (download & install)
#   https://ollama.com/download

# 3️⃣ Create a Python virtual environment
python3 -m venv .venv
source .venv/bin/activate   # or .venv\Scripts\activate on Windows

# 4️⃣ Install Python dependencies
pip install -r requirements.txt

# 5️⃣ Pull a vision‑language model for Ollama (example) – run once
ollama pull llava

# 6️⃣ Run the app
streamlit run app.py
```

## Configuration
- **Ollama model** – edit `config.json` (created on first run) to change the model name.
- **Output folder** – selectable in the UI; defaults to `organized_documents` inside the project.
